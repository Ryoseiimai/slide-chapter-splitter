VREWに台本を自動で入れる、3つの道

結論：VREWには公式のAPIや一括生成の機能はありません。それを前提に、「今すぐ使える半自動」「検証中の自動操作」「VREWを使わない完全自動」の3つを用意しました。

まず分かったこと

VREWの運営チームに直接確認したところ、「APIも一括生成も提供していない」との回答でした。ですので、外部のプログラムからVREWへ台本を自動で流し込む公式な方法はありません。

出典: VREW公式Q&A（ログイン必須）

一方で、2025年7月からブラウザで使える「Web版VREW」が始まっています。実際にログインして開き、「新規で作成」の中に次の3つがあることを確認しました。

  • テキストから動画を作成
  • スライドで動画を作成（PDF・PPT・PPTXを読み込める）
  • AI音声で始める

出典: VREW公式・Web版のお知らせ

3つの道

①今すぐ使える

半自動：Web版VREWの「スライドで動画を作成」

やること：Web版VREWを開く → 「スライドで動画を作成」を選ぶ → 章のPDFを入れる → 台本を貼る → 声を選ぶ、の3手順を章ごとに繰り返す
人がやること：この3手順そのもの（現時点ではボタンを押すのは人）
向いている場面：今日から使いたい、章の本数がそれほど多くない
②実証済み・2026-09-03

自動操作：①をブラウザ自動操作で回す

やること：①と同じ画面を、ブラウザを自動で動かすAI（Claude in Chrome等）に操作させる
人がやること：最初のログインだけ。以降は「章の一覧を渡すと順番に投入する」形にできる見込み
今の状態：今井のVREWアカウントで実際に検証。PDFの投入から台本の流し込み、AI音声の生成まで自動操作だけで通り、動画のプロジェクトが1本できあがるところまで確認済み

実際に試したのは、Web版VREW（vrew.ai）の「新規で作成 → スライドで動画を作成」です。18ページのPDFで、下の4ステップをすべて自動操作で通しました。

ステップ何をしたか自動／人
1/4 PDFアップロード 18ページのPDFを渡して読み込ませた 自動
2/4 台本作成方法の選択 「AIで台本を生成」「スライドのテキストを台本として読み込む」「台本を直接作成する」の3択から「台本を直接作成する」を選択 自動
3/4 台本の流し込み スライド18枚すべての台本欄に、合計684字を自動で流し込み。改行した箇所でクリップが分割される仕様（この画面の上限は30,000字） 自動
4/4 AI音声の生成 「AI音声を使用」をONにし、無料の声（波音リツ／VOICEVOX、クレジット表記で商用可）を選んで完了。約40秒でAI音声が生成され、1分30秒のプロジェクトが「このデバイスに保存済み」になった 声の選択は人、それ以外は自動

完成したエディタ画面。18クリップ・波音リツ・字幕が入っている。

残る人の操作：VREWへのGoogleログイン（初回のみ）、声の選択（1本目で決める）、書き出しボタン
注意：無料プランのAI音声はクレジット消費（100文字＝1クレジット、月200クレジット）。684字の台本で約7クレジット。透かしは無料プランで付く（有料プランで解除）

りょうすけさんの環境で動かすには：Codex等のAIに、ログイン済みのChromeを操作させます（Claude in Chrome、またはPlaywrightに普段使いのChromeプロファイルを持ち込む方式）。章のPDFと、章ごとの台本テキスト（【ページN】の形式で1ページ1段落）を渡せば、上の4ステップを順番に流すだけです。1章＝1プロジェクトになります。

Codex向け技術メモ（実装する人向け）
  • PDFの入力欄（input[type=file]、accept は .pdf,.ppt,.pptx）は「ファイルを読み込む」ボタンを押した瞬間にDOMへ生成される。ボタンの click イベントをフックして捕まえる必要がある
  • PDFファイルは、CORSが許可されたURLから fetch して Blob/File化し、その input 要素の files プロパティに直接セットしたうえで change イベントを発火させる
  • 台本欄の textarea は React 管理下にあるため、value を直接代入しても画面に反映されない。Object.getOwnPropertyDescriptor で取得した prototype の value setter 経由で値を入れ、そのあとに input イベントを発火させる
  • スライドの切り替えは、サムネイル一覧の div に対して pointerdown → mousedown → click の順でイベントを発火させないと選択状態にならない
  • 完了ボタンが画面の見える範囲の外に出ることがあるため、事前に zoom を下げて全体を表示させておく
③代替・完全自動

VREWを使わない完全自動：autovideo

やること：章のPDFとページごとの台本を渡すと、無料の読み上げ（edge-tts）と字幕を焼き込んだmp4を自動で作る
確認済み：実物の章で書き出しを1本試作済み。透かしなし、文字数の上限なし
できあがった動画をVREWに読み込んで、字幕の手直しだけVREWでやることも可能

3つの道の比較

①半自動②自動操作③autovideo
人が手を動かす回数 3手順×章の数 最初のログインのみ（実証済み） ほぼゼロ（PDFと台本を渡すだけ）
今すぐ使えるか 使える 使える（AIに操作させる設定が必要） 使える（試作済み）
動画の透かし 無料枠は冒頭10秒に「Vrew」の透かしが入る ①と同じ（VREW側の仕様のため） なし
1回あたりの文字数上限 「テキストから動画」機能は無料3,000字・有料10,000字（1文＝1クリップ） ①と同じ 上限なし
声の質 VREWのAI音声（複数の声から選べる） ①と同じ Microsoftの日本語音声（Nanami等）
字幕・演出 VREWの字幕編集がそのまま使える ①と同じ 字幕は焼き込み。BGM・画像演出はなし

出典: 文字数上限（公式FAQ） ／ クレジット制・透かしの案内（公式） ／ 料金の説明（公式）

やらないこと

  • .vrewファイル（プロジェクトファイル）を外部から自動生成すること。仕様が公開されておらず、VREW側の更新で壊れやすいため採用しません
  • 無料枠の透かしを消す・回避すること。VREW公式の仕様で、有料プランで解除する以外の回避策は提供しません

誤読対策

台本をそのまま読ませると、「STEP1」などが変な読み方になることがあります。次の2つで対策します。

  • 誤読チェッカーで台本をチェックし、「VREWの発音辞書に登録する語」の一覧をコピーまたはCSVで書き出す（誤読チェッカーを開く）
  • その一覧を、VREWの「AI音声」タブにある「発音辞書」に登録する。固有名詞をひらがな・カタカナに変換でき、部分一致で台本全体に効く。クリップごとに直したい場合は、各クリップの「発音」欄でも変更できる

声の種類を変えたときは、誤読の出方も変わるので、1本目を必ず聴き直してください。

出典: 発音辞書（公式FAQ）

費用の目安

VREWは2026年4月22日からクレジット制です。無料は月200クレジットで、AI音声は100文字＝1クレジット。無料プランは動画冒頭10秒に「Vrew」の透かしが入り、有料プランで解除されます。金額やクレジット数はVREW側の改定で変わるので、実際の申し込み前に公式サイトの最新情報を確認してください。
